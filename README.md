## What I'm building

**Estra Logics** is the platform. **CML — Continuity Markup Language —** is its underlying language and engine. I develop CML as an enhancement to existing software: a way to describe what must remain true, check proposed changes, and preserve a record of the result. Python, JavaScript, and other host tools carry out their own work alongside it.

**Fermata** is the working method around that engineering: observe, pause when a condition is unresolved, check the evidence, and continue when the conditions are met.

The question running through it all is simple: **what must remain true when work changes hands, tools, or form?**
